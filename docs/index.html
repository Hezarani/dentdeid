        Download a clean copy

        De-identified is not anonymous. Teeth, restorations and implants can identify a person. Share only with the patient's consent or under your institution's rules.

        What DentDeID removes — and what it can't.

        Dental images leak identity in more places than a name field. DentDeID checks each one and tells you what it found, without ever showing or storing the values.

        Burned-in text

        Names, dates of birth, IDs and clinic details drawn into panoramic headers, screenshot corners and colour labels. A dental-aware detector is designed not to mistake crowns, restorations, implants and brackets for text. In colour photos, text-like areas are only suggested for you to confirm.

        Hidden metadata

        EXIF camera data, GPS location, capture time, XMP, comments and PNG text chunks — and every DICOM header field, private tag and overlay. The download is a newly encoded PNG or JPEG that carries none of it: no EXIF, XMP, comments, text chunks or colour profile.

        File names

        Exports named like Surname_Name_1987-03-12_PAN.jpg get a neutral name.

        Faces

        Extra-oral photos: blur the whole face, or keep only the smile. CBCT volumes can be rendered into a face — the Python tool flags that risk.

        What no tool can remove

        The dentition itself is identifying — in 2026 forensic studies, software ranked the right person first for 65–75% of panoramic radiographs when searching galleries of about 200 people. And automatic detection can miss faint text drawn over teeth or bone. Always check the Result view yourself before sharing.

        Batches, DICOM-to-DICOM, research datasets

        The Python package applies the full DICOM PS3.15 Basic Profile with keyed pseudonyms, shifted dates, CBCT face-risk checks, fail-closed quarantine and an audit report. It also reads TIFF files and big-endian or compressed DICOM that browsers can't open (some compressions need an extra decoder plugin).

dentdeid run exports/ -o deidentified/ --profile share
